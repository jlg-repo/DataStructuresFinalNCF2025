### Graph to PNG instructions



##### Install graphviz from this site:

###### https://graphviz.org/download/



#### For this tutorial I have downloaded the graphviz 14.0.4 32 bit ZIP archive



##### Once installed, navigate to System Properties (view advanced system settings)

###### Click on Environment Variables

###### Click on Path in the top section, then Edit...

###### Click New and paste the file path to the bin folder from graphviz

###### Confirm everything



###### The Graph Visualizer and generated Dot file must be in the same folder

###### If they are, you can compile and run it to get the PNG



###### Open CMD prompt and ensure the path is set to the folder with your files

###### If it is not, use 'cd <Path>' to get to the folder

###### 

###### Compile the file with 'javac GraphVisualizer.java'

###### Run the file with 'java GraphVisualizer'
